# Nolane HIRA

Research and construction repository for a tiny, non-autoregressive typed decision engine.

The current research target is RD-SD-HIRA: encode state once, compile/cache schemas, preserve full-K probabilities, refine uncertain logical options with a small relation core, and keep OOD/calibration as explicit fail-closed authorities.

## Status

**Research:** open.  
**Construction:** starting from the R6 pre-build freeze.  
**Claims:** no Laya/JEV parity, multilingual parity, final speedup, or scientific novelty is claimed before matched experiments.

The first implementation branch will preserve failed runs, hashes, configs, and benchmark receipts rather than optimizing for a single headline score.
